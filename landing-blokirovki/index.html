Что происходит

С конца сентября пользователи Claude получают письма от Safeguards Team: «internal investigation of suspicious signals… revoked your access». Апелляции отклоняют. Среди пострадавших — аккаунты Max 20x со стажем от пяти месяцев до двух лет.

  • Самый частый названный триггер — VPN: NordVPN, Proton, швейцарский Exoscale.
  • Есть блокировки без VPN: macOS, статический IP, два аккаунта на одну карту.
  • Прошедшие верификацию документов тоже попали под блокировку.
  • В мае 2026 уже была волна по аккаунтам из России, деньги за подписку тогда возвращали.

Источники: треды r/ClaudeCode и r/Anthropic 30 сентября — 1 октября 2026; хроника блокировок на TAdviser, «Продукт: Claude».

Почему с подпиской Veai блокировать нечего

Ключ вместо аккаунта

Claude Code и Codex CLI получают модель через ключ Veai. Входить в аккаунт Anthropic не нужно, значит и терять нечего.

Те же модели

Opus 5.5 и Sonnet 5.5 в подписке, рядом GPT 6 Sol, Gemini 3.1 Pro, GLM 5.3, DeepSeek, MiniMax M3, Kimi K3, Qwen 3.8. Один провайдер отключился — продолжаете на другом в той же подписке.

Оплата в рублях

Российская карта, личный кабинет, без посредников и комиссий. Минута любой модели стоит одинаково внутри тарифа.

Минуты не сгорают

Неиспользованные минуты остаются на счёте, а не обнуляются в конце месяца.

Скиллы и контекст на месте

Меняются две строки в настройках. Проект, MCP-серверы и скиллы Claude Code остаются как были.

Для команд — свой шлюз

В Veai Корпоративный адрес и ключ выдаёт администратор, запросы идут через шлюз в контуре компании. Блокировка личного аккаунта сотрудника не останавливает задачу.

Как подключить Claude Code за три шага

Оформите подписку в личном кабинете

На app.veai.ru выберите тариф. В октябре скидка применяется автоматически при оплате, промокод не нужен.

Скопируйте адрес API и ключ

В кабинете есть блок «Подключение к Veai»: адрес шлюза и ваш личный ключ.

Вставьте две строки в настройки Claude Code

Файл ~/.claude/settings.json:

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.veai.ru/openai/api",
    "ANTHROPIC_API_KEY": "<ваш ключ Veai>"
  }
}

Полные инструкции: Claude Code, Codex CLI, Cursor, весь список инструментов.

Оговорка про CursorClaude Code и Codex CLI — бесплатные клиенты, платят в них только за модель, и ключ Veai закрывает это полностью. Cursor проксирует запросы через свои серверы, поэтому для внешнего шлюза нужны подписка Cursor Pro и VPN — это особенность Cursor, а не требование Veai. Ключ Veai оплачивает модели внутри Cursor, но не саму подписку Cursor.
